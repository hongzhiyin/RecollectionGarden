- 真实英文、嵌入中文字形和纯图像 PDF 正常导入，缩略图与页面实际渲染。
- 改名、刷新及新页面打开后，书籍、文件和已保存页码恢复。

## 验收边界

- 32 MiB 样例为有效 PDF 加尾部空白，2,000 页样例为简单页面；不代表复杂图像和真实长篇 PDF 的性能保证。
- PDF.js 解码设置限制单张图像为 1,600 万像素，超限图像可能不显示；此类文件未完成验收。
- 只在上述 Chrome 环境验证；Safari、Firefox、隐私模式和峰值内存尚未验证。
- 已实现基础笔记、书内检索、来源定位和 Markdown 导出；备份及跨书语义检索尚未实现。完整宿主聊天管理不属于此版本。
- 无备份、跨设备同步或多窗口进度写入接管。
- 文本选取限同页，每段最多 10,000 字符；单页外部读取最多 40,000 字符，个人笔记正文最多 20,000 字符。OCR、跨页选择、双栏语义排序和特殊字形修正尚未实现。
- 真实书籍只完成下述页面和导航流程抽样；未逐页验证 386 页，其他复杂长篇书籍及峰值内存尚未验证。
- 单页渲染不提供连续滚动或缩略图分页；大尺寸页面降低渲染精度。异常关闭仅恢复已提交的位置。
